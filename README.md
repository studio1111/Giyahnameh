# گیاه‌نامه | Giyahnameh

دانشنامه اندرویدی گیاهان جهان با تمرکز بر اطلاعات گیاه‌شناسی، نگهداری، کاربردهای سنتی و شواهد ایمنی.

## وضعیت
نسخه آغازین پروژه در حال ساخت است. این مخزن برای تولید APK با GitHub Actions آماده می‌شود.

## اصول محصول
- Kotlin، Jetpack Compose و معماری داده ترکیبی
- Room برای داده‌های محلی و مشاهده آفلاین
- همگام‌سازی تدریجی داده‌های آنلاین
- تفکیک کاربرد سنتی از شواهد بالینی
- نمایش منابع و هشدارهای ایمنی؛ نبود اطلاعات به‌معنی ایمن‌بودن نیست
- استفاده از تصاویر و داده‌ها با رعایت مجوز و شرایط منبع

## ساخت APK
از زبانه **Actions**، گردش‌کار **Android CI** را اجرا کنید. فایل APK آزمایشی در بخش Artifacts همان اجرا قرار می‌گیرد.

## نکته پزشکی
این برنامه ابزار آموزشی است و جایگزین تشخیص یا درمان تخصصی نیست. اطلاعات مربوط به مصرف دارویی باید با منابع معتبر بررسی شود.
